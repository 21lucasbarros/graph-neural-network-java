# Graph Neural Network (GNN) from Scratch in Java

> **Status:** 🚧 Projeto em desenvolvimento 🚧

## Sobre o Projeto

Este repositório contém uma implementação **do zero** de uma Rede Neural em Grafos (**Graph Neural Network - GNN**) utilizando apenas **Java puro**. O objetivo principal é estudar e demonstrar, na prática, os fundamentos matemáticos da propagação de mensagens em grafos e o funcionamento interno dos neurônios artificiais em estruturas não lineares.

- **Sem uso de bibliotecas de Machine Learning:** Todo o código é implementado manualmente, sem dependências de frameworks ou bibliotecas externas de ML.
- **Foco didático:** O projeto busca ser uma ferramenta de aprendizado, facilitando a compreensão dos conceitos fundamentais por trás das GNNs.
- **Em desenvolvimento:** O projeto está em construção e novas funcionalidades, melhorias e exemplos serão adicionados gradualmente.

## Objetivos

- Explorar os conceitos matemáticos e computacionais das GNNs;
- Implementar todos os componentes essenciais (neurônios, camadas, conexões, propagação de mensagens, etc.) manualmente;
- Fornecer um código-base simples e comentado para fins educacionais;
- Servir como ponto de partida para experimentos e estudos sobre redes neurais em grafos.

## Como Executar

- Importe o projeto em sua IDE Java favorita (IntelliJ, Eclipse, VS Code, etc.)
- Compile e execute a classe `Main.java` localizada em `src/main/java/com/lucasbarros/Main.java`.
